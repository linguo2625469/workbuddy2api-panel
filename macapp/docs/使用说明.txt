WorkBuddy2API 1.0.0 完整包
================================

这个压缩包里有两样东西：
  · WorkBuddy2API-1.0.0-universal.dmg   界面 App（菜单栏小图标）
  · gateway/                            网关程序 wb2api

先解压，再按下面 3 步走。


一、装 App
--------------------------------
1. 双击 WorkBuddy2API-1.0.0-universal.dmg
2. 把 WorkBuddy2API.app 拖进「应用程序」文件夹
3. 第一次双击 App 会提示「Apple 无法验证」，这是正常的：
   点「完成」→ 打开 系统设置 → 隐私与安全性 → 往下找到「安全性」
   → 点「仍要打开」→ 输入开机密码
4. 再双击 App 就能打开，以后不会再问


二、选择网关目录（只需一次）
--------------------------------
App 本身只是遥控器，真正干活的是 wb2api。

   · Apple 芯片（M1 / M2 / M3 / M4）→ 选 gateway/apple-silicon 文件夹
   · Intel 芯片                      → 选 gateway/intel 文件夹

不知道自己是哪种？点屏幕左上角  → 关于本机，看「芯片」一栏：
写着 Apple M… 就是 Apple 芯片，写着 Intel 就是 Intel。

怎么选：App 打开后如果提示找不到 wb2api，
点橙色提示条上的「选择网关目录…」，选上面那个文件夹即可。

建议把这个 WorkBuddy2API-1.0.0 文件夹放到固定位置（比如「文稿」），
App 会记住路径，以后不要移动或删除它。


三、日常使用
--------------------------------
· 打开后，屏幕右上角菜单栏会出现一个小图标，那就是它
· 关掉主窗口服务不会停，图标还在 = 服务在跑
· 点图标可以：打开管理面板 / 停止服务 / 检查更新 / 显示主窗口 / 退出
· 想开机自动启动：主窗口勾选「自启动」
· 想彻底退出：点图标 →「退出」


四、接进 AI IDE
--------------------------------
主窗口点「API 配置」，把三个值填到 IDE 里新增的「OpenAI 兼容」模型：

  Base URL : http://127.0.0.1:18888/v1
  Model    : 下拉里标着「速率 0」的是免费模型，直接选一个
  API Key  : 点右侧图标复制
